An ultra-modern, privacy-first daily toolkit app built with Flutter and GetX. Features an all-in-one suite of 8 essential offline utilities wrapped in a soft, modern glassmorphic interface with day-wise greetings, inspiring quotes, interactive banners, and real-time search.

---

## 🚀 Key Features

- **🌅 Day-Wise Smart Dashboard**: Contextual greetings (Morning, Afternoon, Evening, Night), time-tailored inspirational quotes with refresh cycling, interactive swipeable banners, and quick glance telemetry.
- **🔍 Real-Time Search & Category Filters**: Search tools by name, description, or category (`Productivity`, `Health`, `Finance`, `Utilities`).
- **⏰ World Clock**: International multi-city time zones with live offsets and visual day/night status.
- **🔥 Habit Tracker**: Streak builder and daily checkmarks without any account registration or cloud tracking.
- **💧 Water Intake Tracker**: Interactive hydration meter with quick +250ml loggers and daily goal meters.
- **⌨️ Typing Sprint (WPM)**: 60-second typing test measuring real-time Words Per Minute and accuracy.
- **💰 Smart EMI Calculator**: Instant monthly installments, total interest, and payback calculation with interactive sliders.
- **🎲 Random Decision Maker**: Coin flipper, dice roller, number generator, and custom list picker.
- **⏳ Event Countdown**: Days, hours, and minutes countdown to your milestone dates and events.
- **📱 Device Diagnostics**: Hardware, manufacturer, OS, and system architecture inspector.
- **🔒 Privacy-First**: 100% offline local storage, zero personal tracking.
